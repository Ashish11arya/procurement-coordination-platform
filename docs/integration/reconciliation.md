# Government Integration: End-of-Day (EOD) Reconciliation Protocol

> [!IMPORTANT]
> **Production Integration Notice (Section 39)**
> Automated End-of-Day (EOD) reconciliation ensures that physical stocks procured across all mandi weighbridges match the official ledger in central government portals. Reconciliation reporting rules will align with the final accounting standards of FCI, NAFED, and State Civil Supplies Corporations.

---

## 1. Reconciliation Objective

Every evening after the physical mandi gates close (typically 19:00 IST), the platform executes an automated **Three-Way Reconciliation Audit** comparing:
1. **Physical Ground Ledger**: Local calibrated weighbridge weight receipts generated by Mandi operators (`weighing_records`).
2. **Platform Coordination Ledger**: All bookings finalized in the platform (`procurement_records`).
3. **Central Government Portal Ledger**: Official acknowledgments stored in e-Samridhi / CFPP (`govReferenceId`).

```
+-------------------------------------------------------------------------------+
|                       Three-Way EOD Reconciliation Ledger                     |
+-----------------------+-------------------------------+-----------------------+
|  Mandi Weighbridge    |    Coordination Platform      |   Government Portal   |
|   Scale Records       |     Procurement Records       |     Ledger (CFPP)     |
+-----------+-----------+---------------+---------------+-----------+-----------+
            |                           |                           |
            +-------------[ Matching Net Weight ]-------------------+
            +-------------[ Matching Receipt Number ]---------------+
            +-------------[ Matching MSP Value ]--------------------+
```

## 2. Discrepancy Classification Taxonomy

| Variance Code | Description | Severity | Automated Action | Manual Remediation Protocol |
| :--- | :--- | :--- | :--- | :--- |
| `VAR-01` | **Pending Government Sync**: Physical procurement finalized locally, but government acknowledgment missing due to network outage. | Medium | Scheduled retry worker dispatches batch push. | Operator re-triggers sync from `/admin/integrations`. |
| `VAR-02` | **Weight Reading Variance**: Discrepancy between gross weight on scale and recorded final weight $> 0.1\%$. | High | Alert flagged on Centre Administrator dashboard. | Mandi Superintendent reviews weighbridge scale calibration logs. |
| `VAR-03` | **Sanctioned Quota Overflow**: Farmer's delivered quantity exceeds remaining quota registered on portal. | Critical | Transaction paused with `GovSyncStatus.FAILED`. | Nodal Agricultural Officer reviews land record exception approval. |
| `VAR-04` | **Duplicate Acknowledgment**: Government portal issued multiple reference IDs for the same booking. | Low | Platform de-duplicates and binds canonical first ID. | None required; auto-resolved. |

---

## 3. Discrepancy Resolution & Sign-Off Workflow

1. **Automated EOD Report Generation**:
   - At 19:30 IST, the platform aggregates all transactions for the day across all centres.
   - Computes: Total Quintals Procured, Total Farmer Payout Liability (₹), Synced Records Count, Pending Records Count, Error Count.
2. **Centre Administrator Review**:
   - The Mandi Secretary / Centre Administrator accesses `/centre/exceptions`.
   - Resolves any un-synced receipts by verifying physical paper weight-slips against digital entries.
3. **District & State Sign-Off**:
   - District Civil Supplies Officer reviews reconciled totals on the **Government Command Centre Dashboard** (`/admin/dashboard`).
   - Issues digital cryptographic sign-off acknowledging daily stock procurement tally.
4. **Permanent Audit Trail (Section 26)**:
   - All reconciliation reports, variances, and operator sign-offs are immutably archived with SHA-256 integrity hashes in the `audit_logs` collection.
